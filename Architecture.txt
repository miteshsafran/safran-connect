Step to Install Models in Ollama
1. Download Model From 
    https://huggingface.co/ggml-org/gemma-3-4b-it-GGUF/blob/main/gemma-3-4b-it-Q4_K_M.gguf?utm_source=chatgpt.com
2. dir "C:\Users\DI402833\Desktop\Ms Documents\AI\Models\gemma-3-4b-it-Q4_K_M.gguf"
3. goto folder
    cd "C:\Users\DI402833\Desktop\Ms Documents\AI\Models"
4. create a modelfile
    notepad Modelfile
5. open file and put it 
    FROM ./gemma-3-4b-it-Q4_K_M.gguf

    PARAMETER temperature 0.2
    PARAMETER num_ctx 4096
6. Then run 
    ollama create company-gemma -f Modelfile

7. run below cmd
    ollama run company-gemma
8. Verify 
    ollama list
9. See details 
    ollama ps

Step Install Vector DB in Local
1. Download qdrant-x86_64-pc-windows-msvc.zip
2. create a folder  
    C:\qdrant
3. paste exe in this folder
    C:\qdrant\qdrant.exe
4. Open Terminal
    cd C:\qdrant
5. Start Qdrant
    .\qdrant.exe
6. Keep Terminal open
7. Run in browser
    http://localhost:6333/
